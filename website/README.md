# Saiesha Portfolio

Personal portfolio and blog built with Next.js.

## Run locally

```bash
cd website
npm install
npm run dev
```

Open the local URL shown by Next.js.

## Structure

- `app/page.jsx` - homepage
- `app/blog/page.jsx` - blog index
- `app/blog/what-im-learning-in-2026/page.jsx` - first blog post
- `app/globals.css` - site styling
- `app/layout.jsx` - metadata and root layout

## Deploy

The site is designed to deploy from this folder on Vercel. The GitHub repository is the source of truth for the code.
