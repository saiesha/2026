# Problem Solving

A collection of my ongoing **C++ and SQL** problem-solving practice.

The goal here is not simply to collect solutions. I'm using these problems to strengthen:

- Data structures and algorithms
- Complexity analysis
- C++ implementation skills
- SQL and relational thinking
- Pattern recognition and problem decomposition

## Languages

- C++
- SQL

## How I approach problems

For each problem, I aim to think through:

1. What is the simplest correct approach?
2. Can the time or space complexity be improved?
3. What edge cases can break the solution?
4. Can the implementation be made clearer?

This directory will grow as I work through structured DSA practice and revisit problems to improve my solutions.
